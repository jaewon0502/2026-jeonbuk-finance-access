# 대시보드 검증 기록

갱신일: 2026-10-13 (분석 자료 기준 2026-10-12)

## 목적과 완료 기준

심사위원이 최종 보고서의 수치를 화면에서 확인하고 운영조건을 바꿨을 때의 결과를 구분하도록 한다.
금융접점·거리·경로·지도는 같은 검증 입력을 사용해야 한다. 기본조건의 방문 대상과 이동거리는
보고서와 일치해야 한다. 입력을 바꿔도 이전 결과를 새 계산으로 오해하지 않아야 한다.

## 화면 구성의 선택

기존 자료와 보완 자료를 전환하는 방식도 검토했다. 자료가 섞일 위험을 줄이기 위해 보완 자료만
현재 화면에 적용했다. 제출 당시 군집분석은 과거 기록으로 남겼다.

종합 화면에는 전북 전체의 보고서 결과를 고정했다. 운영 시나리오에서는 선택 범위와 적용한 조건을
결과 옆에 표시한다. 조건을 바꾼 뒤에는 재계산 전이라는 안내를 보여 준다. 결과를 다시 선택하면
그 계산에 사용한 입력도 복원한다. 방법 비교는 동일한 시군별 운영일 배정을 사용한다.
사용자 시나리오는 운영일 배정까지 최적화하므로 두 결과의 의미를 구분한다.

## 보완한 내용

- 접점 1,347곳과 243개 행정동을 연결했다. 품질유보 3곳 중 임계치를 초과한 1곳을 제외해 경로대상은 54곳이다.
- 기본조건은 P1 21곳과 P2 29곳을 방문한다. 이동거리는 1,003.716km다.
- 같은 50곳을 방문한 우선순위 최근접 방법의 1,103.950km와 비교해 100.234km가 짧다.
- 최대 방문 수 3·4·5곳의 비교실험을 연결했다. 방문 대상이 같은 비교와 방문 수만 같은 비교를 구분한다.
- 같은 도로망에서 지도 경로 294개를 다시 만들었다. 계산 행렬과 지도 경로의 최대 차이는 0.000001km다.
- 미방문 지역과 제외 사유를 표시한다. 시간표에는 이동·도착·서비스·복귀 시각을 표시한다.
- CSV에 자료 버전과 계산조건 및 선택 범위를 넣었다. 기존 군집분석을 현재 분석처럼 보이게 하던 선택지는 제거했다.

## 검증과 남은 한계

Python 자료 검사에서 원본 해시와 보고서 집계 및 지도 연결을 확인한다. JavaScript 검사에서는
보고서의 세 방법을 최대 방문 수 3·4·5곳에서 재현한다. 시간표는 원래 행렬로 이동과 시간창을
따로 재검산한다. 실행 명령은 `bash verify_offline.sh`다.

경계 밖 접점은 일부 기관만 보완했다. 실제 영업시간과 업무 범위는 현장 확인 전이다.
대표점 검증은 기하학적 위치 변화에 관한 비교이며 주민 분포를 검증하지 않는다.
후보지는 대상별로 고정돼 있고 차고지와 속도는 가정이다. 장소 승인과 차량 진입 및 교통시간을
확인한 뒤 운영안으로 바꿔야 한다. 이 화면은 주민의 실제 수혜율이나 운영비 절감을 보여 주지 않는다.

## 실행 확인

2026-10-13 로컬 통합 검증을 마쳤다. `verify_offline.sh`가 통과했고 Python 검사 18개와
최종 JavaScript 검사 19개가 통과했다. 브라우저에서 지역 선택과 빈 선택 및 조건 변경 전후 표시를
확인했다. 사용자 입력안의 조건 복원과 키보드 탭 실행도 확인했다. 390px 폭의 세 주요 화면에서
페이지 전체의 가로 넘침은 없었다. 표는 자체 가로 스크롤을 사용한다.

실제로 내려받은 접근성 CSV는 243행이었다. 기본 일정 CSV는 방문 50행과 미방문 4행이었고
경로별 첫 행의 거리 합계는 1,003.716km였다. 06:00~07:00 조건에서는 미방문 54행을
내보낼 수 있었고 시간창 문제를 용량 부족과 구분해 안내했다. 확인한 페이지의 콘솔 오류는 없었다.
현장 운영과 실제 기기별 전체 검증 또는 배포를 확인한 것은 아니다.

확인했다. 공식 조회 기록 83개의 SHA-256과 농·축협 334곳의 업무 표시, 제외된
271곳·334곳의 접점 집합 및 공간분석·경로분석의 대상 집합을 대조했다.

현재 화면에는 방문 대상 54곳·방문 50곳·미방문 4곳과 고창군 기본안의 지도·시간표를
표시한다. 대시보드와 방법 설명에서 이전 버전 대비 변경 내역을 제거했다. 브라우저에서
하루 상한 3곳으로 다시 계산했을 때 43/54곳·912.448km가 나타났고 입력 초기화로

선택하면 4/4곳·73.594km가 표시됐다. 고창군 예시는 09:00 출발·13:50 복귀·73.594km로 일치했다.
