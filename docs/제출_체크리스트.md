## 실행 증거와 제외 범위

- 실행 증거: [verify_offline_log.txt](verify_offline_log.txt). 기준 커밋, 검증 환경, 명령, 종료 코드와 전체 출력을 기록한다.
- 기본 검증은 별도 체크아웃·새 가상환경에서 실행했다. 인터넷은 다운로드·설치에 필요하며 설치 후 검증에는 API 키나 원본 데이터가 필요 없다.
- 기본 검증은 일부 가공 결과와 대시보드 번들을 다시 쓴다. 현재 수치와 과거 결과의 구분은 [result/README.md](../result/README.md)를 따른다.
- 이번 실행 환경은 macOS다. Windows/WSL2·Linux 실기기 실행, 원본 도로망 재구축, 현장 운행은 이번 확인 범위에 포함하지 않는다.

## PDF의 다른 서식 안내

PDF 2쪽의 발표자료·최종 결과보고서·데이터셋 설명서·시연자료 확인서 등은 별도 제출 서식 안내다.
이 대응표는 코드·분석파일 범위를 정리한 것이며, 다른 서식의 작성·서명·제출 완료를 표시하지 않는다.
문서 하단의 서식 통합 의견은 저장소 구성의 필수 요건으로 적용하지 않았다.
