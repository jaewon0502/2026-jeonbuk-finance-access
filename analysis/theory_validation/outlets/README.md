# 금융점포 보완 자료

2026년 10월 12일 농협과 신협의 공식 영업점 조회 자료를 수집했다.
8월 제출본과 같은 시점의 자료라는 뜻은 아니다.
8월 당시 해당 지점이 존재했는지와 실제 운영 중이었는지는 확인하지 않았다.

## 수집 결과

| 자료 | 수집 범위 | 결과 |
|---|---|---:|
| 농협 시도 검색 | 전북특별자치도 / 영업점 / 농·축협 | 332곳 / 42페이지 |
| 농협 지도 범위 검색 | 경도 126~128.1 / 위도 35.1~36.35 / 영업점 | 1,018곳 / 128페이지 |
| 전북 농·축협 대조 결과 | 지도 범위 검색 중 전북 주소 | 334곳 |
| 신협 원문 수집 | 대전·경북·경남·충북·충남·전남광주 조회 | 683곳 |
| 신협 좌표 범위 선별 | 위와 같은 지도 범위 | 214곳 |
| 신협 비교용 후보 | 지역 공동유대 / 전북 밖 주소 | 190곳 |

시도 검색에는 없던 도드람양돈농협 전주지점과 익산군산축협 구암지점이 지도 범위 검색에서 확인됐다.
주소와 좌표는 전북에 해당한다.
검색 결과가 다른 원인은 확인되지 않았다.
전북 농·축협의 통합 후보는 `nh_coops_jeonbuk_reconciled.csv`에 334곳을 담았다.

농협 좌표 범위 검색에는 전북 농협은행 52곳도 포함된다.
이는 기존 자료와 중복되는 분류이므로 추가 점포로 더하지 않는다.
`nh_bank_baseline_crosswalk.csv`에 대조 근거를 남겼다.
고창군청 영업점은 주소가 같지만 공식 지도 좌표와 제출본 좌표가 약 1.51km 다르다.
어느 쪽이 맞는지는 이 수집만으로 확정할 수 없어 제출본 좌표를 바꾸지 않았다.

## 사용 조건

- 농협은 공식 지도의 영업점 탭만 조회했다. ATM과 마트·경제사업장 전용 탭은 조회하지 않았다.
- 농협은행과 농·축협을 공식 분류로 구분했다. 실제 영업시간과 개별 창구 업무는 별도로 확인하지 않았다.
- 이름에 경제사업장이나 마트가 들어가더라도 공식 금융 영업점 분류가 같으면 이름만으로 제외하지 않았다. 해당 항목은 `name_service_review_flag`로 표시했다.
- 신협은 공식 공동유대가 ‘지역’인 곳만 비교용 후보로 남겼다. 지도 범위 안의 직장 신협 7곳과 단체 신협 17곳은 이용 대상 제한을 확인하지 못해 제외했다.
- 신협 2곳의 공식 좌표는 `(0, 0)`이었다. 증평신협 송산지점과 목포우리신협의 무안군 일로읍 지점이다. 이 자료는 좌표 선별에서 빠졌으며 해당 지역에 점포가 없다는 뜻으로 해석하면 안 된다.
- 새 자료의 영업 상태는 공식 목록 등재를 근거로 한 가정이다. 실시간 운영 확인을 마친 자료가 아니다.

## 최종 결합 자료 확인

상위 작업에서 행정구역 경계와 전북 경계 20km 범위를 적용한 뒤 704곳을 추가했다.
전북 농·축협 334곳과 도 경계 밖 농협 316곳과 신협 54곳이다.
전체 1,385곳 중 금융 이용 가능 가정을 적용한 점포는 1,347곳이다.
기존 681행의 원래 필드는 모두 유지됐다.
추가 행의 이름과 주소와 좌표와 조회 시각은 수집 원문에서 만든 자료와 일치했다.
검토 대상 파일의 SHA-256과 검토 결과는 `integration_readonly_audit.json`에 있다.

수집 사각형과 전북 경계 20km 범위가 겹치는 부분만 반영했다.
도 경계 밖의 다른 은행과 새마을금고와 금융 업무를 하는 우체국은 이번 수집에 포함되지 않았다.
따라서 모든 금융기관의 도 경계 점포를 빠짐없이 보완했다는 주장에는 사용할 수 없다.

## 공식 출처와 재현 근거

- [농협 공식 홈페이지](https://www.nonghyup.com/main/psniMain.do): 영업장·판매장 링크가 농협 지도 서비스로 연결된다.
- [농협 공식 영업점 지도](https://nonghyup.ttmap.co.kr/main.jsp): 화면의 공개 조회 요청과 같은 `list_branch_2017.jsp`에 조회 조건과 페이지 번호를 전달했다.
- [농·축협 안내](https://www.nonghyup.com/introduce/organization/nhInfo.do): 기관 안내용 참고 페이지다. 지점 좌표의 원천으로 쓰지 않았다.
- [신협중앙회 신협 찾기](https://www.cu.co.kr/cu/ad/cuSearch.do?mi=100076): 공개 목록의 페이지와 지점 상세 조회 `assc.do`를 사용했다. 상세 응답의 `x`와 `y`가 지도에 전달되는 경도와 위도다.

`raw/`에 받은 HTML과 JSON을 보관했다.
각 요청의 실제 조회 시각과 조건과 응답 해시는 원문 옆의 메타데이터 파일 및 조회별 manifest에 있다.
농협 조회는 UTC 12:24:40~12:27:26에 이뤄졌다.
신협 조회는 UTC 12:29:45~12:31:58에 이뤄졌다.
정확한 시작과 종료 시각은 `source_audit.json`을 기준으로 한다.
수집에 지도 API나 새 인증정보를 사용하지 않았다.

`collect_nh_official.py`와 `collect_cu_official.py`는 저장된 응답을 재사용한다.
`freeze_source_audit.py`는 수집 범위와 건수와 정규화 파일 해시를 고정한다.
원문을 지우고 다시 조회하면 현재 목록이 달라질 수 있다.
